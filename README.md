# Tray Flyout

GNOME Shell 50 extension. Adds a Windows-style `^` button to the top bar that opens the hidden tray icons in a small grid popup. It also stacks the clock as time over date.

Install: copy this folder to `~/.local/share/gnome-shell/extensions/tray-flyout@karim`, log out and back in, then run `gnome-extensions enable tray-flyout@karim`.

Which icons get hidden is set in the `HIDE` list at the top of `extension.js`.
